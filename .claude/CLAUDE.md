#### TASK STRUCTURE ####

- The gambling task has multiple blocks separated by pauses. **Blocks are pauses only — the task context does not change between blocks.**
- **Q values persist across blocks.** Do not reset Q values at block boundaries in any RL model.
- **Perseveration (κ) resets at block boundaries.** The prev_choice indicator should zero out at the start of each new block.
- When computing lag-1 stay/reward pairs with `lag()` in R, do NOT group by block — the cross-block transition is a real trial pair.
- Scripts that iterate explicitly over `participant × block` (using `for` loops with `i in 2:n`) will naturally drop the first trial of each block. This is acceptable for those scripts but is not the preferred behavior.

#### DATA VARIABLES ####

Common column names in task CSVs: `task`, `block_number`, `trial_number`, `choice_key`, `reward`, `is_choice_valid`
Key derived variables: `stay` (1 if same choice as previous trial), `reward_nback` (reward on previous trial)

WM data: `data/ioc-all-fixed-pilot/wm/`, file pattern `ioc-wm_<pid>_SESSION*.csv`
WM K (Cowan's K): `ss * (hit_rate + correct_rejection - 1)`, averaged across set sizes 4 and 8.

#### MODELS ####

- **abkd_2arm** (`models/abkd_2arm/`): α, β, κ, 2-arm bandit. Q values persist across blocks; perseveration resets at block start via `first_trial_in_block`.
- **abkd_3arm / rl_m1_3arm** (`models/abkd_3arm/`): α, β, κ, δ, 3-arm bandit. Q initialized at 0.5 per subject (not per block). This is the primary M1 model.
- **kd_3arm** (`models/kd_3arm/`): κ, δ only, 3-arm bandit.

Posterior density panels:
- Use `stat_density(aes(y = after_stat(density / max(density))), geom = "area", bw = "SJ")` to normalize peak to 1
- Always show: 90% CI segment, median point, median dashed vline, annotation centered at median (`hjust=0.5`)
- `coord_cartesian(ylim = c(-0.17, 1.35), clip = "off")` to allow CI segment below axis

Text: use ASCII only — avoid Unicode minus (`−`), `≠`, or Greek letters in string literals. Use `!=` not `≠`, `-` not `−`.
