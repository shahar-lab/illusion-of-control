# Parameter Recovery: classic_qval_raffle

## Goal
Verify that the `classic_qval_raffle` Stan model can recover its two free parameters
(`alpha_rl`, `beta_rl`) from synthetic data generated by the matching simulator. A
successful recovery (high Pearson r, population posteriors bracketing the true generating
values) confirms that the model is identifiable before it is fit to real data.

## Model
Classic Rescorla-Wagner Q-value model with a raffle structure. On each trial, only a
random subset of `Nraffle` arms (drawn from `Narms` total) is offered to the agent.
Choice probabilities are computed via softmax over the offered subset only.

Two free parameters:
- `alpha_rl`: learning rate, bounded [0, 1] via inv_logit transform (hierarchical inv_logit-normal)
- `beta_rl`: inverse temperature, bounded > 0 via exp transform (hierarchical log-normal)

The raffle constraint means `fit_stan.R` must pass an `offered_arms` integer matrix
[Ndata x Nraffle] to Stan; `Nraffle` cannot be derived from `df$ch_card` and is read
from `cfg.rds`.

## Simulation setup
- Nsubjects = 100, Narms = 8, Nraffle = 4, Ntrials = 200
- Reward schedule: uniform 0.5 win probability for all arms and trials
- alpha_rl drawn from inv_logit(Normal(0, 0.75))
- beta_rl drawn from exp(Normal(-0.25, 0.75))

## Pipeline (via main.R)
1. `generate_data.R` — simulate 100 agents and save cfg, df, params
2. `plot_param_distributions.R` — sanity-check simulated parameter distributions
3. `fit_stan.R` — fit hierarchical Stan model, save fit, medians, population posteriors
4. `diagnostics.R` — HMC diagnostics (divergences, Rhat, ESS) → Diagnostics.pdf
5. `plot_recovery.R` — true vs. recovered scatter for alpha_rl and beta_rl
6. `plot_population_posteriors.R` — population posteriors vs. true generating values
7. `summary_table.R` — Pearson r table → recovery_summary.csv

## Outputs
- `artifacts/`: cfg.rds, df.rds, population_params.csv, individual_params.csv, fit.rds,
  recovered_medians.csv, population_posteriors.rds
- `output/`: Diagnostics.pdf, param_distributions.pdf/.png, param_recovery.pdf/.png,
  population_posteriors.pdf/.png, recovery_summary.csv
